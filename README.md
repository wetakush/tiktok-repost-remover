# tiktok-repost-remover
A browser script for delete all reposts

# EN

# How to use 
1. Open TikTok in your browser.
2. Log in and go to your profile page.
3. Copy and paste the script into the browser console (f12 -> console).
4. Wait
5. If the script stopped running without removing all reposts, refresh the page and repeat step 3.
